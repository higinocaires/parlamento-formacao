# parlamento-formacao

Flutter course project — Web app to explore **Portuguese Parliament** open data (deputies list, search, detail screen).

## Docs

- **[Project context](docs/CONTEXTO.md)** — app overview, architecture, course requirements, current status

## Quick start

```bash
flutter pub get
flutter run -d chrome
```

## Stack

- Flutter (Web + mobile/desktop)
- Riverpod · http · go_router
- API: [Parlamento.pt open data](https://www.parlamento.pt/Cidadania/paginas/dadosabertos.aspx)
